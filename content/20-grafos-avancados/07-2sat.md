## Quando usar

Quando cada cláusula tem a forma (a ou b), incluindo implicações e restrições booleanas que envolvem no máximo duas literais.

## Ideia

Para cada variável x, crie os nós x e não-x. A cláusula (a ou b) equivale às implicações não-a -> b e não-b -> a. O problema é satisfatível se uma variável e sua negação nunca pertencem à mesma SCC.

## Código

~~~cpp
struct TwoSAT {
    int n;
    vector<vector<int>> g, rg;

    TwoSAT(int n) : n(n), g(2*n), rg(2*n) {}

    // Literal: (variavel, valor). true representa x; false representa !x.
    int id(int x, bool val) { return 2*x + (val ? 1 : 0); }
    int neg(int x) { return x ^ 1; }

    void implication(int a, int b) {
        g[a].push_back(b);
        rg[b].push_back(a);
    }

    void either(int x, bool vx, int y, bool vy) {
        int a = id(x, vx), b = id(y, vy);
        implication(neg(a), b);
        implication(neg(b), a);
    }

    vector<int> order, comp;
    vector<char> vis;

    void dfs1(int u) {
        vis[u] = 1;
        for (int v : g[u]) if (!vis[v]) dfs1(v);
        order.push_back(u);
    }

    void dfs2(int u, int c) {
        comp[u] = c;
        for (int v : rg[u]) if (comp[v] == -1) dfs2(v, c);
    }

    bool solve(vector<bool>& ans) {
        int m = 2*n;
        vis.assign(m, 0); comp.assign(m, -1); order.clear();
        for (int i = 0; i < m; i++) if (!vis[i]) dfs1(i);
        reverse(order.begin(), order.end());
        int c = 0;
        for (int u : order) if (comp[u] == -1) dfs2(u, c++);

        ans.resize(n);
        for (int i = 0; i < n; i++) {
            if (comp[2*i] == comp[2*i+1]) return false;
            ans[i] = comp[2*i+1] > comp[2*i];
        }
        return true;
    }
};

// either(x, true, y, false) representa (x OU !y).
// Variáveis são indexadas de 0 a n-1.
~~~

## Cuidados

- Cada cláusula precisa ser traduzida com cuidado para as duas implicações.
- A convenção de IDs é local a esta implementação: par = falso, ímpar = verdadeiro.
- O vetor ans só é válido quando solve retorna true.
- A DFS recursiva pode exigir versão iterativa em instâncias muito grandes.
