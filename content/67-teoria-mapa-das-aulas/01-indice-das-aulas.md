## Pegadinhas encontradas nos slides (já corrigidas nos códigos)

- **Segtree**: o slide dá build O(N log N); o exato é O(N) (2N − 1 nós).
- **Rerooting**: o código do slide usa a soma da raiz original; o certo é `ans[filho] = ans[pai] + n - 2·sub[filho]`.
- **Pontes**: pular o vizinho igual ao pai quebra com arestas paralelas → pular pela id da aresta.
- **Sandro (SPOJ TOPOSORT)**: o juiz pede a menor ordem lexicográfica → min-heap no Kahn.
- **Sapo**: sem módulo a resposta estoura (cresce exponencialmente).
- **Trie** (Python do slide): alocar 10⁶ nós com 26 filhos cada de início gasta muita memória → alocar sob demanda.
- **Hash**: o slide usa B = 10 para visualizar; na prova use base aleatória grande e dois módulos.
